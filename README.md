# Freaky Delivery Dash

תבנה לי משחק שבו יש שליח של מסעדה בשם mc freaky שבה כל הלקוחות משוגעים ומוזרים. והם מזמינים מכתובות מסויימות שכל הזמן יש להם מכשולים בדרך וjump scares שהלקוחות  והוא צריך לנסוע למקום אחר כל הזמן. הבן אדם ינסע על אופנוע והאווירה צריכה להיות קצת אפלה ומפחידה פשוט יוצאים לבן אדם וצועקים עליו משום מקום והכתובות שהוא נוסע אליהן מאוד מבלבלות
